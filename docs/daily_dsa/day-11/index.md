# TITLE OF PROBLEM

Implement `pow(x,n)` 

Input : Parameters `x` and `n` (`n` is integer)
Output : Power of `x` to `n`th

## Example

### Example 1

**Input:** x = 9.88023, n = 3
**Output:** 964.498

### Example 2

**Input:** x = 2.1, n = 3
**Output:** 9.261

### Example 3

**Input:** x = 1, n = 0
**Output:** 1

## Challenge

${O(\log n)} time
